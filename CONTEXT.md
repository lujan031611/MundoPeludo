### Resumen Rápido

* **Aplicación:** Sistema web full-stack para clínica veterinaria y pet shop.
* **Frontend:** React 18, TypeScript, Vite, Tailwind CSS v4 (`MundoPeludoF`).
* **Backend:** Node.js, Express, MySQL (`MundoPeludoB`).
* **Base de Datos:** MySQL `veterinaria` en `localhost:3306`.
* **Rama de Trabajo:** `turnos_dias`.

Para consultar la arquitectura detallada, el modelo de datos, la guía de endpoints y los pasos de ejecución, revisá el archivo completo en [`docs/contexto-aplicacion.md`](docs/contexto-aplicacion.md).
